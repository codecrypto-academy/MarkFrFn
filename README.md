## Cómo usar cada práctica

Cada carpeta contiene su propio `README.md` con instrucciones detalladas. La forma más rápida de arrancar cualquier práctica es:

```bash
cd practica-XX-nombre
bash start.sh
```

## Requisitos comunes

- Node.js v18+
- [Foundry](https://book.getfoundry.sh/getting-started/installation) (`forge`, `anvil`)
- Git
